# 工单主题观察台

本地运行的中文工单文本分析演示：把导入的工单按内容归成可浏览的主题，看主题随时间的变化、
代表工单和关键词，并支持人工改名、合并、把分错的工单移到别处。全部处理在本地完成，
**不需要联网，也不调用任何在线大模型**。

## 运行

```bash
# 1) 准备虚拟环境（唯一的可选第三方依赖是本地中文分词 jieba；缺失时自动退回字符 n-gram）
python3 -m venv .venv
. .venv/bin/activate
pip install jieba            # 可选，但强烈建议：没有它关键词会退化成字符片段

# 2) 载入演示数据（84 条虚构中文工单，5 个批次）
python3 -m app.seed

# 3) 启动服务，打开 http://127.0.0.1:8765
python3 -m app.server 8765
```

数据库默认写到 `data/tickets.sqlite3`（可用环境变量 `TICKET_DB` 指定别的路径）。
想从头再来，可用「批次与训练」里的「重置为演示数据」按钮，或直接删除该文件。

## 页面导览

| 标签 | 能做什么 |
| --- | --- |
| 主题总览 | 工单/去重后/重复投递/待整理/主题数；整月趋势（投诉单量、重复投递、待整理三项分开计数）；每个主题的时间走势、代表工单、关键词 |
| 待整理区 | 短文本、空文本、离群和匹配度不够的记录，按原因分组；可直接移入主题 |
| 批次与训练 | 按月演示批次导入；新批次先按已确认主题匹配，低相似度进入待整理；重新训练后逐条列出新旧主题对应关系 |
| 清理规则 | 调整清理规则与阈值；保存后自动重训并给出修改前后的主题数量与按月趋势对照 |
| 历史与回看 | 每次改名/合并/移动/规则调整都留审计记录与版本快照，可打开展示当时的归类 |

主题卡片点开后：

- **为什么放在一起**：按成员与簇质心的相似度、簇内凝聚度、重复投递数解释；
  关键词只是从聚类中心还原出的归类线索，不代表原文作出了该结论。
- 主题名称可人工修改；也可以把两个主题合并（原主题保留映射，历史趋势按目标主题回看）。
- 每张工单可「原文对照」查看清理前后的逐段对照，或移动到其他主题/移回待整理区。

## 文本管线（全部本地）

1. **清理**（`app/normalize.py`）：按行剥离引用回复（`>` 引用行、`-----原始邮件-----`、`在 xxx 写道：`）、
   签名块（`-- ` 之后的内容、此致/敬礼、落款姓名）、客套 greeting、系统自动页脚和工单号/手机号/日期等模板噪声。
   每一段都保留 `kind`，页面据此展示原文与清理后的逐段对照。
2. **重复投递**：加权字符 3-gram 余弦 + 包含关系，阈值可在规则里调整；少于 10 个字的短语不参与近似判定，
   防止「打不开」「在吗」互相吞并。重复投递跟随首次投递计数，只记 `mentions`，**不计入工单趋势**——
   同一条投诉转发多次不会被算成涨幅。
3. **向量**（`app/embed.py`）：jieba 分词 + 词特征，辅以低权重的字符 3-gram；IDF 加权后 L2 归一化成稀疏向量，
   点积即余弦。稀疏表示让「关键词」直接来自原始特征，可解释、可核对。
4. **聚类**（`app/cluster.py`）：平均连接层次聚类，主阈值之上不再合并；额外的「补合并」只合并两条以上成员的簇，
   避免只共享「退款/到账」的同类工单被拆散，同时保证单条离题工单不会被硬塞进任何主题。
   清理后过短、为空、离群或相似度不足的记录单列待整理区。
5. **主题身份**（`app/pipeline.py`）：重新训练后，新旧主题按**质心余弦相似度**做贪心一对一对齐，
   而不是按簇编号。没对齐上的旧主题标为归档，并给出成员去向（并入哪个新主题或进入待整理）。
   新批次则按已确认主题的质心匹配，低相似度记录进入待整理区。
6. **人工操作**（`app/service.py`）：改名、合并、移动都写审计并保存版本快照；重训后人工移动会按内容重新应用到新主题上，
   目标主题已合并则跟随合并去向，已归档则放弃这条移动而不是把工单挂到不存在的主题。

## 测试

```bash
python3 -m pytest tests -q
```

测试只用标准库 sqlite3 与 pytest，覆盖清理分段、重复投递、短/空文本分离、批次匹配与待整理、
重训按内容对应主题、人工移动/合并/改名及版本回看、规则变更对照。

需要本地分词以获得最好的关键词效果；`app/embed.py` 在没有 jieba 时会自动退回字符 3-gram，功能仍然可用。
